# Various Radix Examples

The javascript project is for easy interaction with the COW token.</br> 
The phyton3 script is to list historical whereabout of the COW token.</br></br>
This repos also holds varous markdown documentation files explaining some
details related to specific Radix Manifests commands.</be>

# requirements
Nodejs/NPM needs to be installed</br>
- <b>note</b>: verify the NPM install version is ok for use with the radix-dapp-toolkit.</br>
Pyhton3 needs to be installed</br>
- <b>note</b>: add missing modules using the pip instructions.</br>

## Getting started: Webclient

In the `root` folder.</br>
- start the website</br>

        %-> npm install	
        %-> npm run dev

This will start the client webserver @localhost:3000

## Getting started: Pyhton
In the `root` folder.</br>
- run the script</br>

        %-> python3 gethistory.py
